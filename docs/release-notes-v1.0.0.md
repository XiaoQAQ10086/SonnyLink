# SonnyLink 1.0.0

用 Android 手机通过 Wi-Fi 遥控老款索尼相机：**实时取景 + 遥控拍摄 + 浏览下载卡内照片**。

> ⚠️ **第三方非官方软件，与索尼公司无任何关联。** 仅供连接你自己拥有的相机。

专为 PMCA 时代（2015 前后）的索尼微单 / 黑卡设计 —— 在这些老机型上，官方 App 启动慢、遥控常连不上、占用电量高。

---

## 这个版本有什么

### 📷 遥控监看

- **实时取景** 640×424 @ 15~20fps，端到端延迟约 100ms
- **GPU 渲染** OpenGL ES 双三次插值放大 + USM 锐化（单 pass）
- **遥控拍摄**，拍完自动取回预览图
- **曝光补偿** −5 ~ +5 EV（1/3 档）
- **自拍定时** 0s / 2s
- **常驻 HUD**：光圈、ISO、快门、曝光模式始终可见
- 自动横竖屏，画面填满屏幕

### 🖼 传输照片

- **按拍摄日期分组**展示卡内全部照片
- **下载全尺寸原图**（如 6000×4000 JPEG）
- 保存位置可选系统相册或**任意自选目录**（SAF）
- **并发下载**，带实时速度显示
- 三级缩略图缓存（内存 / 磁盘 / 网络），二次浏览瞬时响应

### ⚡ 实测性能

| 指标 | 遥控 | 相册 |
|---|---|---|
| 内存 PSS | 155 MB（Native 堆仅 13 MB） | 172 MB，**稳定不增长** |
| CPU | **< 0.5%**（对比 surfaceflinger 18%） | — |
| 帧渲染 | 中位 **8ms**，120Hz 满帧，**0 次错过垂直同步** | 同左 |

- 取景时**自动把屏幕刷新率降到 60Hz** 省电（取景流只有 17fps，高刷纯属浪费）
- **安装包 2.55 MB**（R8 混淆 + 资源压缩）

## 安装

下载下方的 `SonnyLink-1.0.0.apk` 直接安装。

- **要求 Android 10（API 29）及以上**
- 如果装过 debug 版，需要先卸载（签名不同）
- 首次启动会申请「附近的 Wi-Fi 设备」权限 —— 用于读取 Wi-Fi 名称以判断连的是不是相机热点

---

## 使用

相机**一次只能运行一种模式**，所以先在 App 里选：

**遥控监看**
1. 相机 → 应用程序 → **嵌入式智能遥控**
2. 保持相机屏幕显示 SSID / 密码的界面不要退出
3. 手机系统设置里连接相机的 `DIRECT-xxxx:ILCE-xxxx` 热点

   > 系统提示「无法访问互联网」是**正常的**，相机热点不提供上网。

4. 回到 SonnyLink → 遥控监看，App 会自动检测并连接

**传输照片**
1. 相机 → 应用程序 → **发送到智能手机**
2. 手机连接相机热点
3. SonnyLink → 传输照片，自动进入按日期分组的列表

## 已知限制

以下都是**相机本身的限制**，不是本 App 的 bug（官方 App 同样做不到）：

| 限制 | 说明 |
|---|---|
| **不能传 RAW 原文件** | 相机 DLNA 只提供转码 JPEG，请求 `.ARW` 返回 HTTP 406。可选择下载预览图替代 |
| **不能传视频** | 相机的 `GetProtocolInfo` 只声明 JPEG，视频没有 DLNA 资源 |
| **不能触摸对焦** | 固件不支持 |
| **不能拍视频** | `setShootMode(["movie"])` 返回错误 500 |
| **取景固定 640×424** | 相机只提供这一个规格 |
| **缩略图约 0.7 秒/张** | 相机端处理慢，不是带宽问题；已用并发 + 缓存掩盖 |

## 技术要点

逆向过程中真正花时间的地方，完整版见 [README](https://github.com/) 与 [docs/camera-profiles/ILCE-6300.md](docs/camera-profiles/ILCE-6300.md)：

- 取景流是 chunked，且 `payloadSize` 是**相机缓冲区大小而不是 JPEG 长度**，EOI 后面还有陈旧数据，必须自己扫 SOI/EOI
- `getAvailableApiList` **不可靠**（M 档下不返回曝光补偿，但调用其实成功）—— 写操作直接调用，让相机当权威
- DLNA 的 `<Result>` 里 DIDL-Lite 是 **XML 转义的**，不反转义一个条目都解析不出来
- 判断「连的是不是相机热点」必须用 `NET_CAPABILITY_VALIDATED`，**不能用 `NET_CAPABILITY_INTERNET`**（相机热点带 INTERNET 但没有 VALIDATED）
- `LruCache` 必须重写 `sizeOf`，否则传字节数会被当成条目数，**永不淘汰**
